# Fasole — GLB stages

Pune aici fișierele exportate din Blender:

- `fasole_seed.glb` ← primul (gata de folosit în app)
- `fasole_germ.glb`
- `fasole_sprout.glb`
- `fasole_grow.glb`
- `fasole_flower.glb`
- `fasole_mature.glb`

După ce adaugi un fișier nou, marchează `ready: true` pentru el în
`src/pages/lessons/templates/garden/visualAssets.ts`.

Convenții: vezi `docs/garden-fasole-assets.md`.
